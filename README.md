# Harshit Agrawal – Portfolio (React + Vite)

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build in /dist
npm run preview  # preview the production build
```

- Content (projects, experience, skills, awards): `src/data.js`
- Hero code window and terminal: `src/components/CodeWindow.jsx`
- Page layout: `src/App.jsx`
- Styles (dark and light theme tokens at the top): `src/index.css`
- Images: `src/assets/`
